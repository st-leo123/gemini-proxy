# Gemini Proxy & Widget

A lightweight Gemini API rotation proxy and desktop widget.

## Setup Instructions

1. Copy `keys.example.json` to `keys.json`:
   ```bash
   cp keys.example.json keys.json
   ```
   Then replace the placeholder strings in `keys.json` with your actual Gemini API keys.

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the widget:
   - Double-click or run `start-widget.bat`.
